# Planner 结构化输出修复测试记录

测试日期：2026-08-03

## 目标

验证 V2 编剧规划器能稳定生成可通过本地 Schema 校验的场景级剧情合同，避免系统无提示地退回确定性备用计划。

## 发现与修复

- 先前 7 天真实测试能完整通过，但 Planner 共调用 14 次，7 天均退回 `fallback`；根因包括 JSON 输出不稳定、1400 token 预算偏小，以及本地动作校验仅识别少量中文动词。
- 为 Planner 增加 JSON Object 模式、温度 `0` 和 2400 token 预算；该选项同时支持未来的 Vercel Serverless Function 转发。
- 明确要求 3–6 个完整场景、第一场景原样执行开场合同动作、结束合同必须包含可执行下一步。
- 动作校验改为拒绝“待定 / 推进剧情 / wait for more”等空泛占位语，而不依赖单一语言的动词白名单；最终正文仍由剧情合同审查器验证。
- Serverless 单 IP 10 分钟限额从 12 提升至 30，以容纳一次正常日更所需的多次受控 AI 调用，同时保留限流保护。
