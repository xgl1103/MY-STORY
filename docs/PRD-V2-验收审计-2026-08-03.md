## 尚未关闭的验收项

PRD 要求“3 个真实 7 天 run 至少 2 个完整通过，候选版本发布前再有 1 个完整通过”。当前受外部模型响应时间与本地工具单次 2 分钟窗口影响，尚未获得满足该数量门槛的完整 run。因此：

- 不应将当前版本标记为“复赛发布验收完成”；
- 可继续使用 `tests/real-7day-continuity.mjs` 以默认 45 秒单请求上限在可持续后台环境中运行；
- 每次 run 必须保存脱敏 checkpoint，并记录 Planner source、Handoff quality、review findings 和调用计数；
- 在获得门槛要求的完整运行后，再进行 Vercel 部署与演示录制。

`.env.example` 当前含本地测试密钥，未被提交。下一次推送或部署前必须移除该值，并在 Vercel 环境变量中单独配置/轮换 `DEEPSEEK_API_KEY`。
