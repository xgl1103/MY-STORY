# 阅读模式切换与点击翻页设计

## 背景

目前生成结果预览页 `src/views/Preview.vue` 和正式章节阅读页
`src/views/ChapterReader.vue` 都只支持纵向滚动。正式阅读页已有齿轮设置面板，预览页尚无阅读设置入口。
本功能为两处阅读场景增加统一的“滑动 / 翻页”选择，同时保留现有滚动体验作为默认值。

## 目标

- 用户可以在预览页和正式阅读页的齿轮设置中选择“滑动”或“翻页”。
- 滑动模式保持当前纵向滚动行为和视觉样式不变。
- 翻页模式按可视区域自动分页；点击屏幕中心线左侧进入上一页，点击右侧进入下一页。
- 正式阅读页在章节边界继续翻页时自动进入相邻章节。
- 两个页面共享同一阅读模式设置，并在刷新或重新进入应用后恢复。
- 字号、行距或视口尺寸改变后重新分页，并尽量保持原阅读进度。

## 非目标

- 不增加左右滑动手势翻页动画。
- 不保存每个章节的最后阅读页码。
- 不改变章节、评论或生成内容的数据结构。
- 不重做现有字号、行距、亮度、目录和夜间模式功能。
- 不在翻页模式下提供分页式文本编辑器。

## 方案选择

采用 CSS 多栏排版实现分页。内容容器具有固定的可视高度和一列等于可视宽度的列宽，浏览器负责将正文、评论和附加内容连续排入多列；当前页通过水平位移或 `scrollLeft` 控制。

未采用以下方案：

- 按段落实测高度手动分组：可以精细控制断点，但对评论卡片、字号变化和屏幕旋转的处理复杂，容易产生空白页或跳页。
- 按字符数切分：实现简单，但无法保证不同字号、中文标点和评论卡片下的页面高度一致。

CSS 多栏方案能够复用浏览器排版能力，保留现有富内容块，并减少两处页面的重复逻辑。

## 用户交互

### 设置入口

- 预览页顶部右侧新增齿轮按钮，点击后打开底部设置面板。
- 正式阅读页继续使用现有齿轮按钮，在原有字号、行距、亮度选项上方增加“阅读方式”。
- 阅读方式使用二段式按钮：“滑动”“翻页”。当前选项具有明确选中态。
- 预览页和正式阅读页读取及写入同一设置，选择后立即生效。

### 滑动模式

- 保留当前纵向滚动、滚动惯性、文章排版、评论卡片、章节底部按钮和阅读进度计算。
- 不添加横向点击区域，不拦截正文点击。

### 翻页模式

- 阅读内容区域固定为顶部工具栏和底部操作区之间的可视高度，一屏显示一页。
- 屏幕中心线是不可见分界线。正文空白区域左半部分点击上一页，右半部分点击下一页。
- 页间切换不触发纵向滚动；内容不允许水平手动拖动，以点击翻页为唯一翻页操作。
- 正式阅读页第一页继续点击左侧时进入上一章；最后一页继续点击右侧时进入下一章。
- 没有上一章或下一章时保持当前页，不显示错误。
- 切换章节后从新章节第一页开始。
- 点击按钮、链接、输入框、文本框、设置面板、目录面板和命运选择控件时不触发翻页。
- 设置面板或目录打开期间暂停正文点击翻页。
- 预览页进入编辑状态时临时使用现有滚动编辑器；退出编辑后恢复用户选择的翻页模式，阅读方式设置本身不改变。

### 预览页内容范围

预览页的分页范围覆盖当前 `content-area` 中所有可读内容，包括故事正文、事件映射、日记引用和重生成提示，确保任何附加信息都不会因固定高度而不可访问。底部“重新生成 / 编辑 / 确认通过”操作区保持固定在分页区域之外。

### 正式阅读页内容范围

正式阅读页的分页范围覆盖正文段落、穿插评论、章节导航、评论汇总和命运选择区域。交互控件仍可正常点击。章节末页之后的再次右击才触发下一章，而不是在抵达末页时立即跳转。

## 组件与职责

### `src/components/ReadingViewport.vue`

统一承载滑动与分页行为，通过插槽接收实际阅读内容。

职责：

- 根据 `mode` 在纵向滚动布局和 CSS 多栏布局之间切换。
- 使用 `ResizeObserver` 监听容器尺寸和内容尺寸变化。
- 计算总页数、当前页和阅读百分比。
- 处理左右半屏点击并忽略交互元素。
- 发出 `progress-change`、`boundary-prev` 和 `boundary-next` 事件。
- 接收重分页触发标识，在字号、行距、内容或视口变化后重新测量。
- 重新分页时按照旧阅读百分比选择最接近的新页；内容或章节身份改变时回到第一页。

### `src/components/ReadingModeToggle.vue`

只负责渲染“滑动 / 翻页”二段式选择控件，通过 `v-model` 读写模式，不直接访问存储。

### `src/features/reader/readingMode.js`

提供阅读模式常量、合法值归一化和本地存储访问：

- 合法值为 `scroll` 与 `page`。
- 存储键为 `reader_mode`。
- 缺失、无效或读取失败时返回 `scroll`。
- 写入失败不阻断当前会话中的模式切换。

### `src/views/Preview.vue`

- 增加齿轮按钮、设置面板与共享阅读模式状态。
- 使用 `ReadingViewport` 包裹现有预览内容。
- 编辑状态强制视口采用滚动渲染，但不覆盖保存的用户偏好。
- 预览没有章节边界导航，因此边界点击仅停留在第一页或最后一页。

### `src/views/ChapterReader.vue`

- 在现有设置面板中加入 `ReadingModeToggle`。
- 使用 `ReadingViewport` 承载当前 `reader-body` 的内容。
- 将边界事件映射到现有 `goPrev()` 和 `goNext()`。
- 滑动模式继续接收滚动百分比；翻页模式接收页码百分比。
- 字号和行距变化通知阅读视口重新分页。

## 状态与数据流

1. 页面加载时调用阅读模式读取函数，得到 `scroll` 或 `page`。
2. 用户在任一页面切换模式，页面状态立即更新并写入 `reader_mode`。
3. `ReadingViewport` 接收模式、内容身份和重分页触发标识。
4. 滑动模式根据 `scrollTop / (scrollHeight - clientHeight)` 发出进度。
5. 翻页模式根据 `currentPage / (pageCount - 1)` 发出进度；单页内容进度为 100%。
6. 正式阅读页收到边界事件后检查现有 `hasPrev` / `hasNext`，仅在相邻章节存在时导航。
7. 字号、行距、异步评论出现或视口变化后重新测量页数，并用旧进度恢复到最接近页。

## 分页测量规则

- 页面宽度以阅读视口的 `clientWidth` 为准。
- 页面高度以阅读视口的 `clientHeight` 为准。
- 多栏间距设为零，避免点击翻页后露出上一页或下一页内容。
- 总页数依据分页内容的水平总宽度除以单页宽度并向上取整。
- 当前页始终限制在 `0` 到 `pageCount - 1` 范围内。
- 组件首次显示、模式切换、内容更新、字体设置变化和尺寸变化后在下一次 DOM 更新完成时测量。
- 组件销毁时解除 `ResizeObserver` 和窗口事件监听。

## 容错与降级

- `localStorage` 读取失败、值非法或浏览器禁用存储时，默认使用滑动模式。
- `localStorage` 写入失败时保留当前会话选择，不弹出阻塞错误。
- 浏览器不支持 `ResizeObserver` 时使用 `window.resize` 事件重新测量。
- 分页容器宽度或高度为零时暂不计算，保留现有内容；下一次有效布局时重新测量。
- 页数计算得到非有限值或小于 1 时按单页处理。
- 章节边界不存在时点击不产生导航或错误提示。

## 可访问性

- 齿轮按钮和阅读方式按钮具有中文 `aria-label` 或可见文本。
- 选中的阅读方式使用 `aria-pressed` 表达状态，不只依赖颜色。
- 左右点击区域不覆盖可聚焦交互控件。
- 保留现有按钮键盘行为；分页组件额外支持左右方向键翻页，输入控件聚焦时不响应方向键。
- 减少动态动画，页切换采用即时或短距离位移，不引入强制翻页动画。

## 测试策略

### 自动化测试

- 阅读模式归一化：合法值原样返回，缺失和非法值返回 `scroll`。
- 本地存储：默认值、成功恢复、写入以及存储异常降级。
- 页码导航：普通前进/后退、第一页向前、最后一页向后、页码边界限制。
- 进度换算：单页为 100%，多页首尾和中间页百分比正确。
- 重分页：总页数变化后按旧进度映射到合法的新页。
- 源码契约：两个页面都使用统一阅读模式控件与视口，正式阅读设置含“阅读方式”。

### 浏览器验收

- 预览页和正式阅读页的滑动模式与当前版本一致。
- 两页切换翻页后，左半屏与右半屏点击方向正确。
- 正式阅读页首尾页可正确进入相邻章节；无相邻章节时保持不动。
- 目录、齿轮、设置按钮、命运选择和预览编辑操作不会误触翻页。
- 字号、行距、夜间模式和窗口尺寸变化后内容无重叠、丢失或不可达区域。
- 刷新页面以及在预览与正式阅读间切换后，阅读模式保持一致。
- 日间与夜间主题下设置面板、正文和进度条均清晰可见。

### 回归验证

- 运行新增阅读模式测试。
- 运行项目完整 `npm test`。
- 运行生产构建 `npm run build`。
- 检查 Git 工作区只包含本功能相关文件。

## 验收标准

- 默认仍为滑动模式，现有用户无需更改操作习惯。
- 用户能在两处齿轮设置中切换并持久保存阅读方式。
- 翻页时每次点击只移动一页，左右方向和章节边界符合设计。
- 所有正文、评论和附加区域都可到达，交互控件可正常操作。
- 重新分页、存储失败和无相邻章节等边界情况不会导致空白页或页面崩溃。
- 自动化测试、完整测试和生产构建全部通过。
